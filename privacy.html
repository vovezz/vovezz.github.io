Приложение «Напоминалка» (com.vovez.taskreminder) · редакция от 25 октября 2026 г.
Главная English version

Коротко

«Напоминалка» не собирает и не передаёт разработчику никаких данных. В приложении нет рекламы, аналитики, учётных записей и серверов разработчика. Ваши задачи хранятся на вашем устройстве. Вне устройства они оказываются только в резервной копии, и только там, куда её сохранили вы сами.

Какие данные обрабатывает приложение

  • Задачи: название, описание, дата и время, настройки напоминаний и повтора, отметка о выполнении.
  • Настройки: выбранная мелодия (ссылка на звук на устройстве), параметры резервного копирования.

Все эти данные хранятся только во внутренней памяти приложения на вашем устройстве. Разработчик не имеет к ним доступа.

Резервное копирование

Резервную копию вы создаёте только сами. Это делается двумя способами:

Копия в файл

Приложение записывает файл с задачами туда, куда вы укажете в системном окне сохранения Android: например, в Google Диск, Яндекс Диск или другое облачное хранилище. Дальнейшее хранение этого файла регулируется правилами выбранного вами сервиса.

Google Диск

Если вы подключили Google Диск, приложение запрашивает у Google доступ https://www.googleapis.com/auth/drive.file. С этим доступом приложение видит только файлы, которые создало само. Остальные файлы на вашем Диске ему недоступны. Приложение создаёт, читает и перезаписывает в вашем Google Диске один файл «Напоминалка — резервная копия.json» с вашими задачами. Данные передаются напрямую между вашим устройством и Google по защищённому соединению HTTPS. Разработчик и третьи лица их не получают.

Данные, полученные через API Google, используются только для создания и восстановления вашей резервной копии. Они не передаются третьим лицам, не используются для рекламы и не применяются для обучения моделей ИИ. Использование информации, полученной через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отключить доступ можно в настройках приложения или на странице myaccount.google.com/permissions.

Разрешения

  • Уведомления, точные будильники, полноэкранные уведомления, вибрация, работа в фоне нужны, чтобы напоминание сработало вовремя, звучало до нажатия кнопки и появлялось поверх экрана блокировки.
  • Запуск после перезагрузки нужен, чтобы восстановить запланированные напоминания.
  • Отключение экономии батареи (по вашему желанию) нужно, чтобы система не задерживала напоминания.
  • Интернет используется только для резервного копирования в Google Диск.

Удаление данных

Чтобы удалить все данные с устройства, удалите приложение или очистите его данные в настройках Android. Резервные копии удаляются вами в том хранилище, где они лежат, в том числе в Google Диске.

Дети

Приложение не предназначено специально для детей и не собирает данные пользователей любого возраста.

Privacy Policy

Napominalka (com.vovez.taskreminder) · effective October 25, 2026

Summary

Napominalka does not collect any data and does not send any data to the developer. It has no ads, no analytics, no accounts and no developer servers. Your tasks are stored on your device. They leave it only as a backup, and only to a location you choose.

Data the app handles

  • Tasks: title, description, due date and time, reminder and repeat settings, completion status.
  • Settings: the selected alarm sound (a reference to a sound on the device) and backup preferences.

This data is kept only in the app's private storage on your device. The developer has no access to it.

Backups

Backups are created only by you, in one of two ways.

Backup to a file

The app writes a backup file to the location you pick in the Android system file dialog (for example Google Drive, Yandex Disk or another cloud storage). Further storage of that file is governed by the provider you chose.

Google Drive

If you connect Google Drive, the app requests the https://www.googleapis.com/auth/drive.file scope. This scope only gives the app access to files it created itself. The app cannot see any other files in your Drive. The app creates, reads and overwrites a single file, "Напоминалка — резервная копия.json", that contains your tasks. The data goes directly between your device and Google over HTTPS. It never reaches the developer or any third party.

Data obtained through Google APIs is used only to create and restore your backup. It is not shared with third parties, not used for advertising, and not used to train AI models. Napominalka's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

You can revoke access in the app settings or at myaccount.google.com/permissions.

Permissions

  • Notifications, exact alarms, full-screen notifications, vibration, foreground service: needed to ring on time, keep ringing until you respond, and appear over the lock screen.
  • Run at startup: needed to restore scheduled reminders after a reboot.
  • Ignore battery optimizations (optional): keeps the system from delaying reminders.
  • Internet: used only for Google Drive backups.

Deleting data

To delete all data from the device, uninstall the app or clear its data in Android settings. You delete backups yourself in the storage where they are kept.

Children

The app is not directed at children and does not collect data from users of any age.

Changes

If this policy changes, the updated version will be published on this page with a new date.
